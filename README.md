# Football Match App

Веб-приложение для организации любительских футбольных матчей.

## Описание проекта

Проект позволяет зарегистрированным пользователям организовывать футбольные матчи, выбирать площадки, участвовать в голосованиях и распределять игроков по командам.

Приложение использует backend на Python с Flask и базу данных SQLite.

## Функциональность

- Регистрация пользователей
- Авторизация пользователей
- Проверка уникальности логина
- Хранение паролей в хешированном виде
- Добавление, редактирование и удаление футбольных площадок
- Загрузка фотографий площадок
- Создание голосований по дате матча
- Голосование пользователей: "играю" / "не играю"
- Изменение своего голоса
- Просмотр результатов голосования
- Рандомное распределение игроков на две команды
- Сохранение результатов распределения в базе данных
- Виджет прогноза погоды на неделю для Саратова

## Используемые технологии

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Requests
- Open-Meteo API

## Запуск проекта

1. Создать виртуальное окружение:

```python3 -m venv venv```

2. Активировать виртуальное окружение:

macOS / Linux:

```source venv/bin/activate```

Windows:

```venv\Scripts\activate```

3. Установить зависимости:

```pip install -r requirements.txt```

4. Запустить приложение:

```python app.py```

5. Открыть сайт в браузере:

```http://127.0.0.1:5000```
